Резервни копия и обновяване

Всички данни на фирмата са на един сървър. Резервните копия се правят автоматично всяка нощ, но копие извън сървъра е задължително.

Автоматично нощно копие

Инсталаторът настройва копие всяка нощ в 02:30. Всяко копие е един файл /opt/gmsun/backups/gmsun-ГГГГММДД-ЧЧММ.tar.gz с базата данни (pg_dump) и цялата папка с файлове (снимки, документи, лого, datasheets). Пазят се последните 14 копия. Логът е в /var/log/gmsun-backup.log.

Ако автоматичното копие не е включено:

sudo cp /opt/gmsun/deploy/gmsun-backup.cron /etc/cron.d/gmsun-backup

Ръчно копие

sudo /opt/gmsun/deploy/backup.sh

Направете ръчно копие преди обновяване, масова редакция в pgAdmin или голям импорт от Excel.

Копие извън сървъра

Ако дискът на сървъра се повреди, копията на същия диск се губят заедно с него. Изберете поне един начин:

  • Втори диск или външен USB диск, монтиран например в /mnt/backup: 
    sudo rsync -a /opt/gmsun/backups/ /mnt/backup/gmsun/
    Добавете реда в /etc/cron.d/gmsun-backup, за да става след нощното копие: 
    0 3 * * * root rsync -a /opt/gmsun/backups/ /mnt/backup/gmsun/
  • Друг компютър през Tailscale: rsync -a потребител@gmsun:/opt/gmsun/backups/ ./gmsun-backups/
  • Облак (Dropbox, Google Drive, OneDrive) — копирайте файловете от backups/ поне веднъж седмично.

Възстановяване

Внимание

Възстановяването заменя цялата текуща база и файловете с тези от копието.

cd /opt/gmsun
sudo deploy/restore.sh backups/gmsun-20261107-0230.tar.gz

На нов сървър: инсталирайте gmsun с командата от Инсталация, копирайте файла с копието в /opt/gmsun/backups/ и изпълнете горната команда.

Обновяване на системата

Най-лесно — същата команда като при инсталацията. Тя прави git pull и преизгражда, без да пипа .env и данните:

curl -fsSL https://raw.githubusercontent.com/SKuytov/gmsun/main/deploy/install.sh | sudo bash

Или ръчно:

cd /opt/gmsun && sudo deploy/backup.sh && sudo git pull && sudo docker compose up -d --build

Промените в базата (нови таблици и колони) се прилагат автоматично при стартиране. След обновяване: Каталог → Добави липсващи Aerocompact артикули, ако в бележките към версията пише, че има нови елементи.

Обновяване на Ubuntu

Обновленията за сигурност се инсталират автоматично. Веднъж месечно:

sudo apt update && sudo apt upgrade -y
sudo reboot

След рестарт контейнерите се стартират сами.
