Инсталация на сървъра

Инсталацията е една команда на чисто инсталиран Ubuntu Server 26.04 (работи и на 24.04). След 3–5 минути системата е готова за вход.

1. Инсталиране на Ubuntu Server

  1. Свалете Ubuntu Server 26.04 LTS от ubuntu.com/download/server и го запишете на USB флашка (с balenaEtcher или Rufus).
  2. Стартирайте компютъра от флашката и изберете Ubuntu Server (не „minimized“).
  3. Мрежа: свържете кабел. Препоръчително е да зададете фиксиран IP адрес (напр. 192.168.1.50) — в инсталатора или като резервация на адреса в рутера.
  4. Диск: Use an entire disk. Ако има втори диск, оставете го за резервни копия.
  5. Потребител: име на сървъра gmsun, ваш потребител и силна парола.
  6. Отметнете Install OpenSSH server. Не избирайте допълнителни пакети (Docker се инсталира от скрипта).
  7. След рестарта влезте с потребителя си (директно или по SSH: ssh потребител@192.168.1.50).

2. Инсталиране на gmsun с една команда

curl -fsSL https://raw.githubusercontent.com/SKuytov/gmsun/main/deploy/install.sh | sudo bash

Ако имате ключ за Tailscale (вижте Отдалечен достъп), сървърът влиза в частната мрежа без отделен вход:

curl -fsSL https://raw.githubusercontent.com/SKuytov/gmsun/main/deploy/install.sh | sudo TS_AUTHKEY=tskey-auth-xxxxx bash

Какво прави скриптът

  1. Обновява системата, инсталира основни инструменти и автоматични обновления за сигурност.
  2. Инсталира Docker Engine и Docker Compose.
  3. Сваля проекта в /opt/gmsun и създава .env със случайни пароли и ключове (достъп само за root).
  4. Стартира базата данни PostgreSQL 16, API, уеб сървъра и pgAdmin.
  5. Инсталира Tailscale и, при подаден ключ, свързва сървъра под името gmsun.
  6. Настройва защитна стена (SSH, HTTP, Tailscale), нощно резервно копие в 02:30 (пазят се последните 14) и ротация на логовете.

Накрая скриптът отпечатва адресите и паролите — запишете ги. Може да ги видите и по-късно:

sudo cat /opt/gmsun/.env

3. Първо отваряне

  1. От компютър в същата мрежа отворете http://192.168.1.50/ (IP адресът на сървъра).
  2. Влезте с admin@gmsun.local и паролата ADMIN_PASSWORD от .env.
  3. Веднага сменете паролата от Настройки → Потребители.
  4. Продължете с Настройки — фирмени данни, лого, цени.

Каталогът, типовете покриви, правилата за конструкция, матрицата за труд и фирмените настройки по подразбиране се зареждат автоматично при първото стартиране.

6. Ръчна инсталация

Ако предпочитате да контролирате всяка стъпка:

sudo apt-get install -y git docker.io docker-compose-v2
sudo git clone https://github.com/SKuytov/gmsun.git /opt/gmsun && cd /opt/gmsun
sudo cp .env.example .env
sudo nano .env        # SECRET_KEY (openssl rand -hex 32), POSTGRES_PASSWORD, ADMIN_PASSWORD, HTTP_PORT
sudo docker compose up -d --build
sudo docker compose logs -f api   # изчакайте "Application startup complete"

Проверка, че всичко работи:

curl http://localhost/api/health

Очакван отговор: {"status":"ok", ...}.
