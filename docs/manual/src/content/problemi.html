Отстраняване на проблеми

Най-честите ситуации и как да ги решите. Повечето се оправят с рестарт на приложението или с проверка на връзката.

Страницата не се отваря

  1. Сървърът включен ли е и има ли мрежа? От друг компютър: ping 192.168.1.50.
  2. Работят ли услугите? На сървъра: 
    cd /opt/gmsun && sudo docker compose ps
    Всички трябва да са running / healthy.
  3. Ако някоя е спряла: 
    sudo docker compose up -d
sudo docker compose logs --tail=100 api
  4. Проверка: curl http://localhost/api/health.

От терен не се свързва

  • Включен ли е Tailscale на телефона и на сървъра? На сървъра: tailscale status.
  • Ползвате ли адреса от Tailscale (http://gmsun или http://100.x.y.z), а не офисния 192.168…?
  • В Android: Настройки → Сървър — проверка на връзката.

Забравена парола

Друг администратор задава нова от Настройки → Потребители. Ако единственият администратор е забравил паролата, на сървъра:

cd /opt/gmsun
sudo docker compose exec api python -c "from app.db import SessionLocal; from app.models import User; from app.auth import hash_password; s=SessionLocal(); u=s.query(User).filter_by(email='admin@gmsun.local').first(); u.password_hash=hash_password('НоваПарола123'); s.commit(); print('ok')"

Влезте с новата парола и я сменете веднага.

Подредбата е неточна

  • Проверете ширината и височината на равнината в метри — те определят мащаба.
  • Наместете четирите ъгъла точно по ръбовете на покрива.
  • Проверете отстъпа от ръба и разстоянията между модулите.
  • Ориентация „Автоматично“ избира по-добрата от портрет и пейзаж.

3D моделът не се показва

3D изисква WebGL в браузъра. Обновете браузъра (Chrome, Edge, Firefox) и включете хардуерното ускорение. На много стари телефони ползвайте визуализацията върху снимката.

Синхронизацията с доставчика не минава

Нужен е интернет на сървъра. Проверете: curl -I https://green-energy.bg. Ако сайтът на доставчика е променен, синхронизацията може да изисква обновяване на системата — каталогът продължава да работи с текущите данни.

Дискът се пълни

df -h
sudo du -sh /opt/gmsun/backups /var/lib/docker
sudo docker system prune -f

Последната команда трие само неизползвани образи и кеш, не данните.
